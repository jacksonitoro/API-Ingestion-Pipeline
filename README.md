# Public API Ingestion Pipeline

A beginner-friendly data engineering project that ingests data from a public API, stores raw JSON locally, and prepares the pipeline for CSV parsing, transformation, and database loading.

## Current progress
- Project scaffold created
- Virtual environment and dependencies configured
- Logging to console and file implemented
- Config file for paths and source URLs added
- Initial JSON extraction from Open Brewery DB completed

## Next steps
- Add CSV extraction
- Transform raw JSON and CSV
- Load data into SQLite
- Add validation and error handling
